# Fundamentos de Desarrollo Web para Principiantes
## Resumen del Curso
Este curso de 1 hora introduce a estudiantes de secundaria a la creación de sitios web sencillos con HTML y CSS. **¡No requiere descargas!** Solo abre tu navegador web.

**Duración total**: ~60 minutos
**Público objetivo**: Estudiantes de 12 a 17 años sin experiencia en desarrollo web
**Prerrequisitos**: Ninguno
**Herramientas necesarias**: **¡Solo tu navegador web!** (Chrome, Firefox, Safari, Edge)
**📂 Repositorio de código fuente**: [Proyecto en GitHub](https://github.com/DiabeLife-Course-Html-Css/Html-Css-fundamentals-course-DiabeLife)

## Secuencia de la Lección
### Lección 1: ¿Qué es el desarrollo web? 
- **Descripción**: Aprende de qué están hechos los sitios web y por qué HTML y CSS son los componentes básicos.
- **Enlace**: [Ver Leccion 1](https://youtu.be/HqvPvey_Rjg?si=84yTVPUAgizqVEeq)
- **Presentación**: [Ver la presentación](https://www.canva.com/design/DAG4J23OExY/uBSRtTHUiiWY1-gOSgmJMw/edit?utm_content=DAG4J23OExY&utm_campaign=designshare&utm_medium=link2&utm_source=sharebutton)
- **Consejos clave**: Sitios web = Contenido (HTML) + Estilo (CSS); Internet conecta páginas web.
- **Material de apoyo**: Presentación interactiva sobre fundamentos web

### Lección 2: Introducción a HTML 
- **Descripción**: Explora las etiquetas HTML básicas y crea tu primera página web.
- **Enlace**: [Ver Lección 2](https://youtu.be/45G8Ee8FmjM?si=8Uli31coXaF6ClJM)
- **Consejos clave**: Usa `<html>`, `<head>`, `<body>`, `<h1>`, `<p>`; estructura básica del documento.
- **Práctica**: [Clic para programar](https://replit.com/@Diego-AlonsoA72/Curso-HTML) 

### Lección 3: Añadir más elementos HTML 
- **Descripción**: Agrega listas, imágenes y enlaces para que tu página sea interactiva.
- **Enlace**: [Ver Lección 3](https://youtu.be/n_HJbpT2-Ag?si=289jh1DYX4fWCPLs)
- **Consejos clave**: Usa las etiquetas `<ul>`, `<img>`, `<a>`; conecta páginas con enlaces.
- **Práctica**: [Clic para programar](https://replit.com/@Diego-AlonsoA72/Curso-HTML)  

### Lección 4: Introducción a CSS 
- **Descripción**: Dale estilo a tu HTML con colores, fuentes y diseños.
- **Enlace**: [Ver Lección 4](https://youtu.be/rFZHkRRKbe0?si=HyYroh5VAY91Rr68)
- **Consejos clave**: Vincular CSS, usar selectores como `body { background-color: blue; }`; separación de contenido y diseño.
- **Práctica**: [Aplicar estilo con un clic](https://replit.com/@AndresTorresUPC/Leccion-4?v=1) 

### Lección 5: Crear una página web con diseño 
- **Descripción**: Combinar HTML y CSS para crear una página web atractiva con diseño centrado.
- **Enlace**: [Ver Lección 5](https://youtu.be/7Z-7EkztfOA?si=bewHy8xd_XVPRevU)
- **Consejos clave**: Alineación de texto, bordes de imágenes, diseño responsivo básico.
- **Proyecto intermedio**: [Crea tu página con estilo](https://replit.com/@ikerbarturen659/Aplicaciones-Web?v=1) 

### Proyecto Final: Perfil Personal Completo 
- **Descripción**: Crea una página de perfil personal completa usando todos los elementos aprendidos.
- **Enlace**: [Ver Proyecto Final](https://youtu.be/_uZpT1Zkes4?si=mhhpZmPSQDaBX_ej)
- **Consejos clave**: Integración de imagen de perfil, secciones organizadas, diseño profesional.
- **Proyecto Final**: [Crea tu Perfil Personal](https://replit.com/@StephanoEspinoz/Pagina-Web-Basica)

### Lección 6: Consejos y Próximos Pasos 
- **Descripción**: Mejores prácticas, errores comunes y dónde aprender más desarrollo web.
- **Enlace**: [Ver Lección 6](https://youtu.be/d0KXho9j12Q?si=gSnuXmIcjcXkYCjs)

## 📚 Contenido de las Lecciones

### Lección 1: ¿Qué es el desarrollo web?

**Descripción**

Esta lección introduce los conceptos fundamentales del desarrollo web. Los estudiantes aprenden la diferencia entre contenido (HTML) y presentación (CSS), y comprenden cómo funcionan los sitios web.

**Presentación**: [Ver presentación interactiva](https://www.canva.com/design/DAG4J23OExY/uBSRtTHUiiWY1-gOSgmJMw/edit?utm_content=DAG4J23OExY&utm_campaign=designshare&utm_medium=link2&utm_source=sharebutton)

**Conceptos clave**
- Internet y la World Wide Web
- Diferencia entre HTML (estructura) y CSS (presentación)  
- Navegadores web y cómo interpretan el código
- Sitios web estáticos vs dinámicos básico

**Material de apoyo**
- Presentación visual sobre la estructura de internet
- Ejemplos de sitios web famosos y su estructura
- Demostración de inspector de elementos del navegador

---

### Lección 2: Tu Primera Página Web

**Descripción**

Esta lección enseña la estructura básica de un documento HTML. Los estudiantes crean su primera página web con elementos fundamentales como encabezados y párrafos.

**Código (index.html)**

```html
<!DOCTYPE html>
<html>
<head>
    <title>Mi Primera Página</title>
</head>
<body>
    <h1>Bienvenido a Mi Sitio Web</h1>
    <p>Este es mi primer párrafo. Estoy aprendiendo HTML.</p>
    <p>HTML significa HyperText Markup Language.</p>
    <p>Con HTML puedo crear páginas web increíbles.</p>
</body>
</html>
```

**Enlace del proyecto**: [Ver en Replit](https://replit.com/@Diego-AlonsoA72/Curso-HTML)

**Conceptos clave**
- Estructura básica del documento HTML (`<!DOCTYPE>`, `<html>`, `<head>`, `<body>`)
- Etiquetas de encabezado (`<h1>`, `<h2>`, etc.)
- Párrafos con `<p>`
- Elemento `<title>` para el título de la pestaña
- Sintaxis de etiquetas de apertura y cierre

**Resultado esperado**
- Una página web simple con título y tres párrafos informativos
- Comprensión de la jerarquía de elementos HTML

---

### Lección 3: Elementos Interactivos

**Descripción**

Esta lección amplía el conocimiento HTML agregando listas, imágenes y enlaces. Los estudiantes aprenden a hacer sus páginas más ricas en contenido e interactivas.

**Código (index.html)**

```html
<!DOCTYPE html>
<html>
<head>
    <title>Mis Cosas Favoritas</title>
</head>
<body>
    <h1>Mis Cosas Favoritas</h1>
    
    <h2>Mis comidas favoritas:</h2>
    <ul>
        <li>Pizza</li>
        <li>Hamburguesas</li>
        <li>Helado</li>
    </ul>
    
    <h2>Mi imagen favorita:</h2>
    <img src="https://via.placeholder.com/300" alt="Imagen de ejemplo">
    
    <p>Visita mi sitio favorito: <a href="https://www.google.com">Google</a></p>
</body>
</html>
```

**Enlace del proyecto**: [Ver en Replit](https://replit.com/@Diego-AlonsoA72/Curso-HTML)

**Conceptos clave**
- Listas no ordenadas (`<ul>`) y elementos de lista (`<li>`)
- Imágenes con `<img>`, atributos `src` y `alt`
- Enlaces con `<a>` y atributo `href`
- Jerarquía de encabezados (`<h1>`, `<h2>`)
- URLs externas y accesibilidad básica

**Resultado esperado**
- Página web con contenido estructurado y elementos interactivos
- Comprensión de atributos HTML y su función

---

### Lección 4: Introducción a CSS

**Descripción**

Esta lección introduce CSS (Cascading Style Sheets) para dar estilo a las páginas HTML. Los estudiantes aprenden a vincular archivos CSS y aplicar estilos básicos.

**Código (index.html)**

```html
<!DOCTYPE html>
<html>
<head>
    <title>Mis Cosas Favoritas</title>
    <link rel="stylesheet" href="style.css">
</head>
<body>
    <h1>Mis Cosas Favoritas</h1>

    <h2>Mis comidas favoritas:</h2>
    <ul>
        <li>Pizza</li>
        <li>Hamburguesas</li>
        <li>Helado</li>
    </ul>

    <h2>Mi comida favorita:</h2>
    <img src="https://encrypted-tbn0.gstatic.com/images?q=tbn:ANd9GcQCjUDxXKtszoBJFQbvj8UL2CbVwJVxyM_3iJUHisxHHxpTzGMvolq9XlqSBiI9_SyA38058uL0M-X0ZnRMjjNdUZDXWZ8DnIf0__PTAZc&s=10" alt="Imagen de mi comida favorita">

    <p>Visita mi sitio favorito: <a href="https://www.google.com">Google</a></p>
</body>
</html>
```

**Código (style.css)**

```css
body {
    background-color: lightblue;
}

h1 {
    color: darkblue;
    font-family: Arial;
}

p {
    color: navy;
    font-family: Verdana;
}

li {
    color: darkgreen;
}
```

**Enlace del proyecto**: [Ver en Replit](https://replit.com/@AndresTorresUPC/Leccion-4?v=1)

**Conceptos clave**
- Vinculación de archivos CSS con `<link rel="stylesheet">`
- Selectores de elementos (`body`, `h1`, `p`, `li`)
- Propiedades CSS: `background-color`, `color`, `font-family`
- Separación de contenido (HTML) y presentación (CSS)
- Colores predefinidos en CSS

**Resultado esperado**
- Página web con estilos visuales aplicados
- Comprensión de la relación entre HTML y CSS

### Lección 5: Página con Diseño

**Descripción**

Esta lección enseña conceptos de diseño más avanzados usando CSS. Los estudiantes aprenden sobre alineación de texto, diseño de listas y bordes decorativos.


**Código (style.css)**

```css
body {
    background-color: lightblue;
    text-align: center;
}

h1 {
    color: red;
}

h2 {
    color: green;
}

ul {
    list-style-type: none;
    padding: 0;
}

li {
    color: darkgreen;
}

    border: 5px solid black;
}
```

**Enlace del proyecto**: [Ver en Replit](https://replit.com/@ikerbarturen659/Aplicaciones-Web?v=1)

**Conceptos clave**
- Alineación de texto con `text-align: center`
- Estilos de color personalizados (`color: red`, `color: green`)
- Eliminación de estilos de lista con `list-style-type: none`
- Bordes decorativos con `border: 5px solid black`
- Enlaces externos funcionales
- Organización de contenido temático (comida rápida vs saludable)

**Resultado esperado**
- Página web temática sobre comidas favoritas con diseño centrado
- Comprensión de estilos CSS avanzados y personalización de colores
- Implementación de enlaces externos funcionales
- Organización visual clara con diferentes tipos de contenido

